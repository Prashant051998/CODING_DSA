# Coding & DSA Solutions

My personal collection of solutions to coding-challenge problems, written mostly in C++ while practicing data structures and algorithms.

## What's in here

The repo holds two kinds of problems mixed together:

- **LeetCode** — classic interview/DSA problems: Two Sum, 3Sum, Container With Most Water, Valid Parentheses, Merge Intervals, Sort Colors, Spiral Matrix, and many more.
- **CodinGame** — puzzle-style challenges: Shadows of the Knight, Mars Lander, There is no Spoon, and several Clash of Code rounds.

Each file/folder is named after the problem it solves. Most solutions are a single `.cpp` file; a few are in their own folder when they needed more than one file.

## Building

Any of the `.cpp` files can be compiled with a modern C++ compiler:

```bash
g++ -std=c++17 "Two Sum.cpp" -o twosum
./twosum
```
